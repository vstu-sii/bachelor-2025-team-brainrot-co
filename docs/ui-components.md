## 1. Экран Авторизации

-   **Название экрана**: Авторизация
-   **Назначение**: Интерфейс для входа пользователя.
-   **Макет**:
    -   Центрированный прямоугольный блок с закруглёнными углами.
    -   Заголовок: "Авторизация" в верхней части.
-   **Элементы**:
    -   **Поле ввода 1**: Плейсхолдер "Email", предназначенный для ввода email.
    -   **Поле ввода 2**: Плейсхолдер "Password", предназначенный для ввода пароля.
    -   **Кнопка**: "Войти", расположена под полями ввода, служит для отправки формы.
    -   **Текстовая ссылка**: "Нет аккаунта?" под кнопкой для перехода к регистрации.
-   **Поведение**:
    -   Пользователь вводит учётные данные в поля.
    -   Нажатие на "Войти" запускает процесс авторизации.
    -   Ссылка "Нет аккаунта?" перенаправляет на страницу регистрации.
	-   Ссылка "Не помните пароль?" перенаправляет на страницу регистрации.

## 1.2. Экран Авторизации с Ошибкой

-   **Название экрана**: Авторизация - Ошибка
-   **Назначение**: Отображение неудачной попытки входа с сообщением об ошибке.
-   **Макет**:
    -   Тот же центрированный прямоугольный блок с закруглёнными углами, как в стандартном экране авторизации.
    -   Заголовок: "Авторизация" в верхней части.
-   **Элементы**:
    -   **Поле ввода 1**: Плейсхолдер "Email", предназначенный для ввода email.
    -   **Поле ввода 2**: Плейсхолдер "Password", предназначенный для ввода пароля.
    -   **Кнопка**: "Войти", расположена под полями ввода, служит для отправки формы.
    -   **Текстовая ссылка**: "Нет аккаунта?" под кнопкой, вероятно, для перехода к регистрации.
    -   **Индикатор ошибки**: Сообщение "Неверные данные" под вторым полем ввода, указывающее на неудачную попытку.
-   **Поведение**:
    -   Пользователь вводит неверные учётные данные.
    -   Нажатие на "Войти" запускает процесс авторизации и приводит к состоянию ошибки.
    -   Ссылка "Нет аккаунта?" перенаправляет на страницу регистрации.
	-   Ссылка "Не помните пароль?" перенаправляет на страницу регистрации.

## 3.1. Главная Страница

-   **Название экрана**: Главная Страница
-   **Назначение**: Интерфейс для взаимодействия с чатами.
-   **Макет**:
    -   Кнопка профиля в правом верхнем углу.
    -   Левый сайдбар с элементами управления.
    -   Центральная область для чатов и ввода вопросов.
-   **Элементы**:
    -   **Сайдбар**:
        -   Кнопка "Новый чат"
        -   Секция "Chats" с несколькими элементами:
            -   "Чат 1" (повторяется несколько раз).
    -   **Центральная область**:
        -   Поле ввода "How can I help you" с плейсхолдером "Message Brainrot AI".
-   **Поведение**:
    -   Пользователь может выбрать чат из списка в сайдбаре.
    -   Нажатие на "Новый чат" открывает новый чат.
    -   Ввод текста в поле "Message Brainrot AIn" и отправка.

## 3.2. Главная Страница с Закрытым Сайдбаром

-   **Название экрана**: Главная Страница - Закрытый Сайдбар

    -   Сайдбар скрыт, доступны только основные действия через иконку открытия.
    -   Нажатие на иконку открытия разворачивает сайдбар.
    -   Ввод текста в поле "Message Brainrot AI" и отправка.
